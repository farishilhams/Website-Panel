This is a [React 19](https://react.dev/) + [Vite](https://vite.dev/) project integrated with an [Express.js](https://expressjs.com/) backend and [Supabase](https://supabase.com/) PostgreSQL database for the **Website Panel MPStore**.

## Getting Started

First, run the development server:

```bash
npm run dev
# or to run both frontend and backend server concurrently:
npm run dev:all
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

You can start editing the page by modifying `src/App.jsx` or components in `src/pages/`. The page auto-updates as you edit the file.

This project uses [Tailwind CSS](https://tailwindcss.com/) for modern glassmorphism styling, [Lucide Icons](https://lucide.dev/), and [Supabase](https://supabase.com/) for cloud database and storage management.
